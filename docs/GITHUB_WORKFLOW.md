# GitHub workflow

1. Open Issue / CR-SHP-001
2. Baseline current repository
3. Create feature branch
4. Implement + tests
5. Push branch
6. Pull Request
7. CI
8. Supervisor review
9. Independent verifier
10. Merge develop
11. Staging
12. Acceptance
13. Merge main
14. Production deploy
15. Rollback by known commit/version if needed
