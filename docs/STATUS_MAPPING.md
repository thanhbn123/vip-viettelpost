# Status mapping

VIPORDER canonical statuses:

- DRAFT
- READY_TO_CREATE
- CREATED
- READY_TO_PICK
- PICKED
- IN_TRANSIT
- OUT_FOR_DELIVERY
- DELIVERED
- DELIVERY_FAILED
- RETURNING
- RETURNED
- CANCELLED

Không điền mã trạng thái Viettel Post bằng suy đoán. Chỉ cập nhật bảng mapping sau khi đối chiếu tài liệu chính thức.
